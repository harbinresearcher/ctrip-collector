# 多地区目录续跑

0.18 起，多地区目录任务会生成 `discovery-regions-随机编号.json` 和同名 TXT。中断或失败后，在窗口选择“继续地区目录”，在链接框填写该 JSON 的完整路径，选择输出目录，再点击开始。建议继续使用原输出目录。

命令行示例：

```text
CtripCollector.exe --resume-regions 地区报告.json --output 数据目录
```

续跑使用报告内原地区清单、每地区页数上限和对象上限。已按原预算结束且快照校验通过的地区会复用；失败或未处理的地区会重新发现。前次得到的对象保留并去重，窗口显示当前地区进度。

续跑粒度是地区，不是该地区的中断页码。预算结束、目录结束或已复用均不代表平台全部数据已采全。报告损坏或内容被修改时停止，不会猜测并继续。0.17及之前的旧格式地区报告没有所需快照，不能直接用于本功能；可重新启动目录任务或使用旧 TXT 清单采评论。
