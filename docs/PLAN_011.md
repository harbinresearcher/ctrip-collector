# 0.11 酒店目录

目标：酒店搜索列表正常翻页生成酒店清单，接入既有评论批处理。前提：系统Edge和本项目独立登录目录；未登录时等待用户在浏览器内登录，不复制凭据。匿名SEO页仅15家，不作为完整目录方案。

1. hotel_discovery.py：解码首屏Flight JSON的initListData；仅解析JSON，不执行页面脚本文本。验证页码，酒店城市、ID与名称，过滤广告，保存公开酒店字段，排除roomInfo会员报价、追踪字段与账号状态。
2. 浏览器监听34951/fetchHotelList，核对请求城市及响应页码；正常滚动加载后续页，错误、超时、重复页、取消均保存已得清单，不称全量。页预算和对象预算限制工作量。登录目录不随包交付。
3. 接入既有--city-list和GUI城市目录入口，生成规范酒店详情链接后走既有酒店评论采集。测试错误城市/页码/失败响应、去重、广告、取消、超时及已有批处理。
4. 真实两页目录与小样评论串接，独立审查、全回归、EXE复验和独立解压后才发布0.11；0.10保留。目录只代表查询日期和筛选条件下的结果，不宣称全城市酒店。

证据：evidence/hotel-list-probe-v011.json已观察首屏initListData（第1页13条，含广告），滚动后fetchHotelList（第2页12条，含广告），响应pagingInfo回显页码。实际过滤后数量待验证。此为历史探查，后续重新验证登录及接口状态。
