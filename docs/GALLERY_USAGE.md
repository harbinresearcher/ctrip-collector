# 酒店AI图集试验功能

本功能包含在0.12测试版，仍处于试验阶段。

1. 手机打开目标酒店的评论页，进入“AI优选住客晒图”，停在网格顶部，不要先打开单张图片。
2. 电脑选择“酒店 AI 图集（试验）”，选择酒店类型，填写该酒店的数字ID和输出目录。
3. 在“目录 / 图集页数上限”填写本次要处理的页数，先用2至5页测试。点击“开始 / 继续保存”。
4. 保持手机解锁并留在携程。需要停止时点击“停止并保存”。

程序先记录缓存基线，再选择AI优选并打开首张。不是首张、布局未知、手机锁屏或切出携程时停止。每页自动识别主图区并记录结果。

- 根目录图片：本次唯一匹配的缓存文件，不保证是上传原图。
- `review`目录：多版本待核对文件，同一页可能有多个版本，不能按文件数当作图集图片数。
- `gallery-run-*.json`：每页结果和停止原因。到达末页不代表每张都已采到。

无匹配时会补查最多16个近期旧缓存候选；候选总量仍受32项和50MB限制，较早缓存仍可能漏配。请关闭遮挡携程主图的悬浮窗口，否则像素匹配可能失败。当前没有自动恢复到上次页码的功能，再次开始需返回网格顶部；已有文件按内容哈希去重。酒店ID由操作者填写，尚未自动核验与当前页面一致。
