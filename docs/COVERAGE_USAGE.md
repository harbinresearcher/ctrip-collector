# 本地数据覆盖报告

在窗口选择“统计本地数据覆盖”，把输出目录设为已有采集结果的目录，点击开始。也可运行：

```text
CtripCollector.exe --coverage --output 数据目录
```

报告文件名为 `coverage-随机编号.json`。程序读取目录内的网络评论数据库及对象文件，按对象统计评论数、来源状态，以及正文、图片、视频、回复、评分和发表时间的字段覆盖。报告不包含评论正文。

每类字段的 `present` 表示已采评论中存在对应字段；`nonempty` 表示字段有内容；`missing` 表示没有该字段。坏数据行另计 `invalid_rows`，不计入字段统计。AI总结、图集状态来自对象文件，不代表内容完整。

报告只统计本地网络评论库，不包含手机界面采集库、平台未返回的数据或其他输出目录；显示总数不代表已采数量，`complete` 固定为 `false`。
